Scaffold Studio

把「下一步要解释什么」改成「此刻最小、最可能有效的帮助是什么」。这是给教师编排、给 Agent 调度的英语学习 Scaffold Skills 原型。

覆盖边界：这里是 30 个 scaffold skills + 1 个 regulation policy，不是英语语料库。音频、transcript、目标句和例句组由教师或上游 Agent 提供；should have 只是可替换样例。

Skill cards

30 个 Scaffold Skills，外加 1 个难度调节器

每张卡既是教师可以直接填内容的课堂工具，也带有 Agent 可读的 trigger、success signal 与 next candidates。

点击任意组件，可打开一个最小交互演示与它的 YAML 规格。内容用 should have gone 作为样例，但每一个字段都可以替换成教师自己的课程材料。

Combination grammar

先解决前置瓶颈，再进入下一层

典型顺序是：感知 → 意义 → 概念 → 输出 → 反馈 → 反思。它不是每次都完整经过六层；如果证据足够，只调用其中一个环节，然后 fade。
